# 🧠 AI Odyssey: Deep Learning Explorer | డీప్ లెర్నింగ్ ఎక్స్‌ప్లోరర్

An interactive, bilingual (English & Telugu) web portal designed for students, developers, and AI enthusiasts to explore Deep Learning concepts through visual analogies, live neural network simulation, activation function graphing, and self-assessment quizzes.

---

## ✨ Features

- **🌐 Full Bilingual Support**: Toggle instantly between **English** and **తెలుగు** across all topics, analogies, and quizzes.
- **🔊 Built-in Audio / Text-to-Speech**: Listen to lessons in English or Telugu using the browser's native Speech Synthesis API.
- **🍎 Interactive ANN Fruit Classifier Simulator**:
  - Select fruit attributes (Color & Shape) and watch real-time signals propagate through Input Nodes $\rightarrow$ Hidden Layers $\rightarrow$ Output Classification with confidence scores.
- **🚪 Interactive Activation Functions Playground**:
  - Experiment with **ReLU**, **Sigmoid**, and **Softmax** across an interactive value slider ($-5$ to $+5$).
  - Theater security guard analogy explaining threshold behavior.
- **📦 Python Ecosystem LEGO Box**:
  - Direct code examples for **TensorFlow**, **Keras**, and **PyTorch**.
- **⚡ Advanced AI Architectures**:
  - Deep-dive into **CNN** (Computer Vision), **RNN & LSTM** (Sequential Memory), and **Transformers & GenAI** (Self-Attention & LLMs).
- **🎯 Interactive Knowledge Check Quiz**:
  - Instant validation with explanatory feedback and a confetti burst celebration upon scoring 100%.

## 🛠️ Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/siliconbrainsai/Deep-Learning-Explorer.git
cd Deep-Learning-Explorer
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run preview
```
